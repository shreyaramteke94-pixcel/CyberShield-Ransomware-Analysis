## 📌 Project Overview

CyberShield is a Flask-based web application designed to analyze potentially malicious files in a secure environment and provide threat intelligence information. The platform focuses on ransomware-related file analysis, hash generation, metadata extraction, and report generation while operating in an isolated and safe workflow.
--- 
## 🎯 Objectives

- Upload suspicious files securely
- Generate SHA-256, MD5, and SHA-1 hashes
- Extract file metadata
- Identify ransomware indicators
- Generate professional PDF analysis reports
- Maintain historical scan records
- Provide an intuitive web dashboard
- Build a modular and scalable backend architecture

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shreyaramteke94-pixcel/CyberShield-Ransomware-Analysis.git
```

Move into the project directory

```bash
cd CyberShield-Ransomware-Analysis
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r backend/requirements.txt
```

Run the application

```bash
python backend/app.py
```
